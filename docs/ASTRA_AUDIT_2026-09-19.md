## 확인된 결함과 이번 수정

1. **TS 기본작가 미연결**: `runtime-author-adapter.ts`가 문자열 TS 프리셋을 native AiAuthor/AuthorIdentityCore로 변환한다. `runtime-authors.ts`에서 TS 12인을 기존 카탈로그 앞에 추가한다. 기존 기본작가 ID·객체·저장된 커스텀 프로필은 삭제하지 않는다. 첫 이관 단계에서는 기존+TS 작가가 함께 보이는 의도적 보존 정책이다.
2. **문체와 플롯 혼합**: `author-voice.ts`에 재사용 집필 범위 계약을 둔다. 전문 분야는 집필 허용목록이 아니다. 문체 속도와 이야기 속 시간/변화 속도를 분리한다. 인물 말투와 작가의 서술 보이스도 분리한다.
3. **작가 정체성 누락/혼합**: `writing-directive.ts`는 실제 identityCore 문자열을 출력한다. 편집된 native identity 컨텍스트가 있으면 기본 프리셋을 다시 섞지 않는다. 기존 컨텍스트와 기억을 story-guides에서 전달할 수 있게 보완한다.
4. **누락값의 숨은 기본 플롯**: 선택하지 않은 혼합비율·표현 비중을 새로 강제하지 않는다. 사용자가 지정한 의뢰·사실·제외사항은 보존한다.
5. **연속성 규칙이 사건 생성으로 변함**: genre.ts에서 '관계 변화 누적' 대신 '이미 발생한 관계/지식 상태 유지'로 보정한다. 미정 사실을 사전의 관습으로 채우지 않는다.
6. **수치만 다른 작가**: `voice-fingerprints.ts`에 12인의 서로 다른 관찰·독자관계·언어의 기원·표현 습관·피할 습관을 설계했다. 미르(대사 타이밍), 하루(캐릭터 반응 주변 서술), 아오이(지정 시점에 밀착한 반응)를 구분했다. 이 자료가 실제 출력의 차이를 보장한다고 주장하지 않는다.

## 작가 고유성 평가 설계

동일한 성인 인물, 사건 순서, 지정 시점, 대사 목적, 금지 전개, 분량 범위를 고정한다. 일반 생활극/거친 어조의 비연애 갈등/차분한 감정극 등 서로 다른 의뢰를 사용한다. 전문 분야와 다른 의뢰도 포함한다.

- 내용 준수: 새로운 연애·갈등·발각·변신·결말을 전문성 때문에 주입했는지, 지정 인물 말투를 바꿨는지.
- 고유성: 문장 리듬, 어휘, 서술 거리, 비유 밀도, 대사 주변 서술의 차이.
- 적응력: 요청된 어조는 수행하면서 고유성이 남는지.
- 읽기 품질: 같은 감정 반복/과한 설명/맥락 없는 장식이 있는지.
- 자동 수치(문장 길이 등)는 보조 자료다. 이름 가린 독자 평가와 함께 판단한다.
