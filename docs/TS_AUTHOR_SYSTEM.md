# 진폭 TS STUDIO — AI 작가 시스템 절충안

## 결론

작가를 단순화하지 않는다. **작가 선택과 생성 UI만 단순화하고, 기존의 깊은 작가 정체성·기억·대화·성장 구조는 유지한다.**

기존 진폭 1.5V의 강점은 AI 작가가 단순 프롬프트 프리셋이 아니라 하나의 콘텐츠라는 점이다. TS판에서도 이 정체성을 유지한다.

## TS판에서 바꿀 겉면

작가 카드와 기본 생성 화면에서는 다음만 우선 노출한다.

1. 작가 이름과 한 줄 정체성
2. 대표 TS 타입 + 추가 타입
3. 대표 부장르 + 추가 장르
4. 대표 분위기 + 추가 분위기
5. 집필 강점 2~4개
6. 짧은 문체 설명

사용자는 이 정보만 보고도 작가를 고를 수 있어야 한다.

## 고급 작가 설정

기존의 깊은 정체성 코어는 `고급 작가 설정` 아래에 유지한다.

추가로 문체를 손쉽게 조절하기 위한 6개 축을 둔다.

- 문장 길이
- 대사 비율
- 전개 속도
- 내면 비중
- 묘사 밀도
- 감각 묘사

수치 자체를 집필 프롬프트에 그대로 넣기보다 자연어 지침으로 변환해서 사용한다.

## 작품과 작가의 역할 분리

- `TS CORE`는 작품의 사실과 변신 규칙, 연속성을 지킨다.
- `AI 작가`는 같은 사실을 어떤 문체와 감정, 장면 구성으로 보여줄지 결정한다.

같은 작품 설정이라도 작가를 바꾸면 독자가 체감하는 결과가 달라져야 한다.

## 작가 정체성 우선 원칙

진폭 TS STUDIO의 집필 철학은 **“무슨 장르의 무슨 작품을 이 작가가 쓴다”**이다.

작품 설정이 작가를 덮어쓰지 않는다. `TS 타입 / 부장르 / 분위기 / 한국·일본·서양·혼합형 서사 프리셋 / 취향·소재 / 표현 비중`은 작가에게 전달되는 **작품 의뢰서**다. 실제 문장, 장면 선택, 감정 해석, 대사, 강조와 생략, 보상 장면의 방식은 작가의 정체성에서 나온다.

### 제약과 창작 주도권을 분리한다

**절대 제약**
- 사용자의 이번 회차 명시 지시
- 이미 확정된 설정·상태·연속성
- 작품 제외사항

이것들은 작가도 위반하지 않는다.

**창작 주도권**
- 기존 진폭 `identityCore`
- `writingStyle`
- `coreDirectives`
- 작가 기억·성장·회고 결과
- 작가의 문체와 서사적 본능

위 제약을 지키는 범위 안에서는 **작가 정체성이 최상위 창작 기준**이다.

### TS 전문성은 작가 위에 덮는 프리셋이 아니다

TS 전문 타입, 분위기, 일본/서양형 장르 관습, 페티시·취향 태그는 작가가 다룰 소재와 작품 방향을 제공한다. 같은 `빙의 + 현대일상 + 약피폐`라도 윤슬, 하진, 미르가 쓰면 서로 다른 작품처럼 느껴져야 한다.

장르 프리셋이 강해져 모든 작가가 같은 TS 문체로 수렴하는 것을 실패로 본다.

## 작품 생성 화면과 연결

작품의 `TS 타입 / 부장르 / 분위기`와 작가의 전문 프로필을 비교해 추천 작가를 정한다.

추천은 절대 평가가 아니라 단순 적합도이며, 사용자는 언제든 다른 작가를 선택할 수 있다.

추천 이유 예시:

> 하진 추천 — 빙의, 약피폐, 심리 중심 설정과 겹칩니다.

숫자 퍼센트는 기본 UI에서 숨기고, 추천 이유를 자연어로 보여주는 것을 우선한다.

## 생성 UX

### 빠른 생성

- 이름
- 대표 TS 전문
- 선호 분위기
- 강점 2~4개
- 한 줄 작가 설명
- `AI가 작가 완성`

AI가 기존 `writingStyle`, `coreDirectives`, `identityCore`를 생성한다.

### 고급 생성

빠른 생성의 모든 항목 + 문체 조절 + 기존 작가 정체성 코어 직접 편집.

## 핵심 원칙

**깊이는 내부에 남기고, 입구만 쉽게 만든다.**

**작품은 작가를 바꾸는 프리셋이 아니라, 작가가 자기 방식으로 해석하고 써내는 의뢰다.**

진폭 TS STUDIO에서 AI 작가는 단순 프리셋이 아니라 선택·수집·육성·융합·분석할 수 있는 핵심 콘텐츠로 유지한다.
