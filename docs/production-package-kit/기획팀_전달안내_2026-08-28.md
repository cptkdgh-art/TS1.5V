# 진폭 제작패키지 기획팀 전달 안내

## 결론

제작패키지의 최상위 형식은 계속 `v1`이다. 기존 패키지도 진폭스튜디오에서 가져올 수 있다.

다만 2026-08-28 최신 규격에는 장편·시리즈 운용을 위한 선택 필드가 추가됐다. 앞으로 새 기획 패키지를 만들 때는 최신 스키마와 예시를 기준으로 작성한다.

## 이번에 달라진 핵심

### 1. 시리즈 권 연결

- `Series.blueprint.volumes[].id`: 권 청사진의 고유 ID
- `Novel.seriesVolumeId`: 작품이 연결될 권 청사진 ID
- `volumeNumber`: 화면 표시와 정렬용 숫자

권 삭제·순서 변경·1권과 2권 교체가 일어나도 연결을 유지하려면 숫자만 맞추지 말고 고유 ID를 연결해야 한다.

### 2. 집필 집중 설정

`Novel.episodePacing`은 아래 구조를 사용한다.

```json
{
  "isEnabled": true,
  "goal": "재단에 대한 작은 위화감을 확실한 의심으로 키운다.",
  "scope": "until-complete",
  "destination": "주인공이 제한 구역을 직접 확인하기로 결심한다.",
  "speed": "normal"
}
```

- `scope: "next-chapter"`: 다음 1화에만 적용
- `scope: "until-complete"`: 사용자가 종료할 때까지 여러 회차에 걸쳐 적용
- `goal`: 진행할 전개 방향
- `destination`: 도달할 상태. 장기 집중에서 선택적으로 사용
- `speed`: `slow`, `normal`, `fast`

장기 집중은 한 화에서 전부 해결할 세부 체크리스트가 아니다. 여러 회차에 걸쳐 자연스럽게 접근할 방향과 도달 상태를 적는다.

### 3. 집필 분량과 연속 집필

- `chapterTargetCharacters`: 한 회차 목표 글자 수. `2000~15000`, 기본 `6000`
- `chapterGenerationMode`: `single`, `extended`, `batch2`, `batch3`

원고가 없는 순수 기획 패키지라도 작품의 기본 집필 운영값을 미리 지정할 수 있다.

## 기존 패키지와의 호환

- `kind`는 계속 `jinpok-production-package`
- `schemaVersion`은 계속 `1`
- `scope`, `destination`, `seriesVolumeId`, 집필 분량·방식 필드는 선택 항목
- 옛 JSON을 가져오지 못하게 만드는 변경은 아님
- 새 필드가 없으면 진폭스튜디오가 기존값 또는 기본값으로 해석

따라서 기존 패키지를 전부 다시 만들 필요는 없다. 앞으로 새로 제작하거나 대대적으로 수정하는 패키지만 최신 규격을 적용한다.

## 기획팀에서 AI에게 전달할 요청문

아래 문장과 이 ZIP의 나머지 파일, 작품 기획자료를 함께 AI에게 전달한다.

```text
첨부된 진폭 제작 패키지 v1 최신 규격, JSON Schema, 완성 예시를 모두 읽고
진폭스튜디오 1.5V에서 바로 가져올 수 있는 제작 패키지 JSON을 작성하라.

기존 설명을 임의로 축약하거나 설정을 새로 지어내지 말고, 제공 자료를 규격의 해당 필드에 배치하라.
시리즈 작품은 Series.blueprint.volumes[].id와 Novel.seriesVolumeId를 정확히 연결하라.
장기 전개 방향이 있으면 episodePacing.scope를 until-complete로 두고,
goal에는 여러 회차의 전개 방향, destination에는 최종 도달 상태를 구분해 기록하라.

최종 출력은 설명과 마크다운 코드블록 없이 유효한 JSON 객체 하나만 출력하라.
kind는 jinpok-production-package, schemaVersion은 1로 유지하고,
출력 전 ID 연결, manifest.counts, JSON 문법을 자체 검증하라.
```

## 검수 체크

- JSON만 출력됐는가
- `kind`와 `schemaVersion`이 정확한가
- 작가·시리즈·작품 ID가 중복되지 않는가
- 작가와 작품 연결이 맞는가
- 시리즈 권 ID와 작품의 `seriesVolumeId`가 맞는가
- 장기 목표가 한 화짜리 사건 목록으로 과도하게 쪼개지지 않았는가
- 세계관 파일이 핵심 규칙부터 우선순위 순으로 배열됐는가
- API 키·인증정보·원격 캐시가 제외됐는가
- `manifest.counts`와 실제 배열 개수가 일치하는가
