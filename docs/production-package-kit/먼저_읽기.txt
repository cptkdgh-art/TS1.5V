진폭 제작 패키지 v1 - 전달용 묶음
최신 갱신: 2026-08-28

이 폴더를 작품 자료와 함께 다른 사람 또는 AI에게 전달하면 된다.

기획팀은 먼저 "기획팀_전달안내_2026-08-28.md"를 읽는다.
기존 v1과 호환되며, 안정적인 시리즈 권 매핑·집필 분량·연속 집필·집필 집중 범위가 확장되었다.

사용 순서

1. AI에게 다음 세 파일을 함께 제공한다.
   - 기획팀_전달안내_2026-08-28.md
   - AI_GENERATION_GUIDE.md
   - jinpok-production-package-v1.schema.json
   - jinpok-production-package-v1.example.jinpok.json
   - jinpok-production-package-v1.series-example.jinpok.json

2. AI_GENERATION_GUIDE.md의 "AI에게 그대로 주는 요청문" 아래에
   작가, 작품, 세계관, 인물, 기획안 또는 원고 자료를 붙인다.

3. AI가 출력한 JSON 객체만 UTF-8 파일로 저장한다.
   권장 파일명: 진폭_제작패키지_{작품명}_r1.jinpok.json

4. 진폭스튜디오 1.5V 홈의 제작 패키지 센터에서
   "패키지 가져오기"를 눌러 만든 파일을 연다.

주의

- 전체 스튜디오 백업 파일과 제작 패키지는 서로 다른 형식이다.
- kind는 jinpok-production-package, schemaVersion은 1이어야 한다.
- API 키, 인증 정보, 앱 설정, 원격 캐시 정보는 넣으면 안 된다.
- AI 출력 앞뒤에 설명이나 마크다운 코드 블록이 붙으면 제거하고 JSON 객체만 사용한다.
- 시리즈 작품은 volumeNumber만 쓰지 말고 Series.blueprint.volumes[].id와 Novel.seriesVolumeId를 연결한다.
- 장기 집필 방향이 있으면 episodePacing.scope를 until-complete로 쓰고 goal과 destination을 구분한다.
