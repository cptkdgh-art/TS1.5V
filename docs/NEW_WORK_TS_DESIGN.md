# 진폭 TS STUDIO — 새 작품/시리즈 생성 v0.1

## 목표
기존 범용 웹소설용 새 작품 생성 화면을 TS 전문 창작 흐름으로 교체한다.

첫 화면에서 사용자가 지나치게 많은 세부 설정을 선택하게 하지 않는다. 대신 작품의 핵심 방향만 잡고, 변화 속도·가역성·정신 변화·기억 변화 등 깊은 설정은 작품 생성 후 TS 세부설정에서 다룬다.

## 첫 화면 구조

### 1. 작품 유형
- 단편/독립 소설
- 시리즈

### 2. 작품 언어
- 한국어
- English

UI 언어와 원고 집필 언어는 별도 설정 가능하도록 데이터 구조를 유지한다.

### 3. TS 방향
대표 1개 선택.
- 남→여
- 여→남
- 가변
- 기타

### 4. TS 타입
대표 1개 + 추가 다중선택.

기본 노출 후보:
- 성전환
- 변신
- 빙의
- 바디스왑
- 환생·전생
- 더보기

더보기 후보:
- 여장·남장
- 가죽·스킨
- 후타나리
- 현실개변
- VR·아바타
- 수술·신체개조
- 기타

예:
- 대표: 가죽·스킨
- 추가: 빙의, 현실개변

### 5. 부장르
TS가 어떤 웹소설 장르/배경 안에서 전개되는지를 지정한다.
대표 1개 + 추가 다중선택.

기본 노출 후보:
- 현대일상
- 현대판타지
- 판타지
- 학원·아카데미
- 직장
- 인방·방송

더보기 후보:
- 연예계
- 로맨스
- 코미디
- 피폐
- 이세계
- 게임·시스템
- 헌터
- SF
- 호러
- 미스터리

### 6. 분위기
대표 1개 + 추가 다중선택.

기본 노출 후보:
- 힐링
- 코믹
- 잔잔
- 설렘
- 약피폐
- 피폐

더보기 후보:
- 나데나데
- 로맨틱
- 당혹·수치
- 긴장
- 극피폐
- 구원
- 몽환
- 공포
- 미스터리
- 서정적

### 7. 작품 핵심
기존 `주제·소재 추가 설명` 대신 사용한다.

사용자가 태그만으로 표현되지 않는 이야기의 핵심, 보고 싶은 전개, 관계, 변화 방향 등을 자연어로 입력한다.

예:
> 평범한 남자가 친한 여사친의 모습으로 변한다. 처음에는 하루가 지나면 돌아오지만 변신을 반복할수록 원래 몸으로 돌아오기 어려워진다. 주변 사람들이 조금씩 눈치채는 전개를 보고 싶다.

## 시리즈 모드
TS 방향·TS 타입·부장르·분위기는 시리즈 공통 규칙으로 저장한다.

추가 입력:
- 시리즈 제목
- 시리즈 전체 핵심
- 1권 제목
- 1권 핵심 전개

예:
- 시리즈 전체 핵심: 남→여 변신이 반복될수록 복귀가 어려워지는 현대일상물
- 1권 핵심 전개: 첫 변신 발생, 정체를 숨기며 일상에 적응하는 단계까지

후속 권은 시리즈 공통 TS 설정을 상속하고 권별 핵심 전개만 별도로 관리한다.

## UX 원칙
1. 전문성은 깊게 제공하되 첫 화면은 지치지 않게 한다.
2. TS 타입, 부장르, 분위기는 복수선택 가능하다.
3. 복수선택 중 대표 1개를 지정하여 AI가 작품의 중심을 잃지 않게 한다.
4. 사용자가 세부 태그를 몰라도 작품 핵심 자유입력만으로 시작할 수 있다.
5. 세부 TS 설정은 작품 생성 후 별도 화면으로 확장한다.
6. 내부 데이터는 언어 중립 ID를 저장하고 한국어/영어 UI 라벨을 분리한다.

## 1차 구현 범위
- TS 방향
- TS 타입: 대표 + 추가
- 부장르: 대표 + 추가
- 분위기: 대표 + 추가
- 작품 핵심
- KO/EN 원고 언어
- 시리즈 전체 핵심 / 1권 핵심 분리

변화 속도, 가역성, 정신·기억 변화, 주변인 인지, 금지요소 등은 2차 TS 세부설정으로 이관한다.
