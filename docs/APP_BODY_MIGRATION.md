# 진폭 TS STUDIO — 앱 몸통 이관 계획

## 기준 소스
- 원본: `cptkdgh-art/jinpok-studio-v1.5`
- 기준 브랜치: `codex/ts-studio`
- 기준 커밋: `0a10dff94194f3e48ff96877942f8b5cbc43a72d`
- 대상: `cptkdgh-art/TS1.5V`
- 작업 브랜치: `feat/app-body-migration`

## 원칙
1. 기존 진폭 1.5V의 기능과 AI 작가 정체성 구조를 최대한 보존한다.
2. TS 전용 코어를 덮어씌우는 방식이 아니라 기존 앱의 생성·저장·집필 흐름에 연결한다.
3. `main`은 현재 확정된 TS 설계 기준점으로 보존하고, 실행 앱 이관은 작업 브랜치에서 진행한다.
4. 작품 설정은 작가에게 주어지는 의뢰서이며, 제약을 위반하지 않는 범위에서 창작 주도권은 작가 정체성이 가진다.
5. 회차 생성·이어쓰기·재작성·장면확장 등 모든 실제 원고 생성 경로에 TS 활성 집필 지시문을 연결한다.

## 1차 관통 목표
`앱 실행 → 새 TS 작품/시리즈 생성 → AI 작가 선택 → 1화 생성 → 저장 → 2화 이어쓰기`

이 흐름에서 다음을 확인한다.
- TS 방향/타입/부장르/분위기/작품 핵심 저장
- 취향·스타일 접힘 설정 저장
- 한국/일본/서양/혼합형 프리셋 반영
- 기존 AI 작가 identityCore / writingStyle / coreDirectives 유지
- 선택 작가의 개성이 결과 문장과 장면 선택에 드러남
- TS CORE의 연속성 원칙이 함께 적용됨
- 시리즈 공통 설정과 권별 핵심 분리

## 이관 순서
### A. 실행 골격
- package / Vite / TypeScript / ESLint / PostCSS
- `src/main.tsx`, `src/App.tsx`, 전역 스타일
- shared components / icons

### B. 저장과 타입
- `@core/types`
- storage / stores
- novel / series / author 데이터 구조
- 현재 TS 코어와 충돌 없이 병합

### C. 작가 시스템
- 기존 AI 작가 관리
- identityCore
- 작가 기억 / 일반 대화 / 성장 회고
- 복제 / 융합 / 텍스트 분석 / AI 추천
- TS 전문 프로필을 추가 레이어로 연결

### D. 작품 생성
- 기존 CreateWorkModal을 TS 전용 생성 흐름으로 개조
- 대표 1개 + 추가 다중선택
- 작품 핵심
- 취향·스타일 고급 영역
- KO/EN 원고 모드
- 시리즈 전체 핵심 / 1권 핵심

### E. 집필 엔진
- 기존 AI 생성 서비스 보존
- 기존 작가 정체성 컨텍스트를 최상위 창작 주체로 연결
- `buildTsWritingDirective()`를 실제 회차 집필 경로에 연결
- 이어쓰기/재작성/확장 경로까지 누락 검사

### F. TS 상태 엔진
- 현재 몸/원래 몸
- 변화 단계
- 가역성/복귀 조건
- 정신·기억·자아 변화
- 관계/호칭
- 비밀 인지자
- 조건/대가/부작용

### G. 검증
- 동일 소재를 서로 다른 작가에게 작성시켜 문체/장면 선택 차이 확인
- 3~5화 연속 생성 후 상태 오류 검사
- 한국어/영어 원고 각각 확인

## 완료 기준
단순히 앱이 빌드되는 것이 아니라, 같은 작품 설정을 서로 다른 작가에게 배정했을 때 **작가 이름을 가려도 결과의 문체·장면 선택·감정 해석 차이가 체감**되고, 장편에서도 TS 상태가 무너지지 않는 것을 1차 완료 기준으로 삼는다.
